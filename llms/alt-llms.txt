# Alt

> Alt (alt.xyz) is an alternative-asset platform for high-value graded trading cards. Collectors and
> investors research, value, buy, sell, vault and borrow against slabbed sports cards, Pokemon and other
> trading-card games in one place. Alt operates a fixed-price marketplace, timed and "Liquid" auctions,
> an Instant Pricer, a physical vault in Delaware, and card-backed lending, all underwritten by Alt
> Value — a machine-learning pricing model, tuned by card-pricing specialists, that produces a real-time
> value for every BGS, PSA and SGC card vaulted with Alt.

## API status

Alt publishes **no public developer program**. As of 2026-08-02 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract offered to third parties, no SDK, no CLI, no sandbox,
no MCP server, no A2A agent card, and no self-service API signup. The alt.xyz web and mobile
applications are served by a private platform backend that is not documented or offered externally.
No `/.well-known/` discovery documents are published on any Alt host. This entry is a company profile
in the API Evangelist network; it is not an API listing.
